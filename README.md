# Sistema Multiagente Pedagógico com Agentes Inteligentes

Este repositório apresenta um **Sistema Multiagente Pedagógico** desenvolvido como parte do trabalho da disciplina **Residência Tecnológica – Porto Digital**, com mentoria da **Accenture**. O objetivo do projeto é demonstrar como agentes inteligentes podem atuar de forma coordenada para apoiar processos de ensino-aprendizagem em plataformas educacionais baseadas em IA.

## 🎯 Objetivo do Projeto

Desenvolver um **ecossistema de agentes inteligentes especializados**, capaz de:

* Explicar conteúdos;
* Diagnosticar lacunas de conhecimento;
* Motivar o estudante;
* Gerar exercícios personalizados;
* Avaliar o desempenho;
* Produzir relatórios em diferentes níveis de profundidade.

Esse modelo simula uma arquitetura moderna de sistemas educacionais inteligentes, promovendo personalização, eficiência e autonomia no processo de aprendizagem.


##  Arquitetura Geral

O sistema segue uma abordagem de **Multi-Agent System (MAS)**, onde cada agente possui responsabilidade clara, comunicação definida e capacidade de atuar de maneira independente e colaborativa.

### **1. Agente Tutor de Conteúdo**

Responsável por explicar conceitos com clareza, adaptar explicações ao nível do aluno e fornecer exemplos contextualizados.

### **2. Agente Diagnóstico**

Analisa respostas e interações para identificar lacunas cognitivas, erros recorrentes e grau de domínio sobre cada tópico.

### **3. Agente Motivacional**

Gera feedback positivo, reforço construtivo e mensagens que mantêm o engajamento.

### **4. Agente Criador de Exercícios**

Produz questões personalizadas com base no nível cognitivo atual do estudante: múltipla escolha, dissertativas, desafios práticos, etc.

### **5. Agente Avaliador**

Corrige respostas automaticamente, atribui notas, identifica padrões e registra evolução.

### **6. Agente de Relatórios**

Gera documentos sobre desempenho, trilha de aprendizagem, recomendações e métricas de progresso.

## 🏛️ Motivação e Contexto

Com a crescente adoção de IA na educação, sistemas multiagentes se destacam por permitir:

* Personalização em escala;
* Modularidade na expansão de funcionalidades;
* Tomada de decisão distribuída;
* Aprendizagem contínua do sistema com base nos dados do aluno.

Neste projeto, buscamos aproximar a teoria dos **Intelligent Tutoring Systems (ITS)** com práticas modernas utilizadas por empresas líderes em tecnologia, como a Accenture.

##  Tecnologias e Metodologias

* Arquitetura multiagente
* Lógica baseada em regras e inferência
* Fluxos de comunicação entre agentes
* Conceitos de sistemas distribuídos
* Práticas modernas de UX educacional
* Modelagem de agentes cognitivos

##  Possíveis Expansões

* Adoção de LLMs para cada agente
* Dashboard analítico para professores
* Geração dinâmica de trilhas completas de estudo
* Integração com dados de plataformas reais

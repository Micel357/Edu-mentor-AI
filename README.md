# Edu Mentor AI — sistema multiagente pedagógico

Proposta acadêmica de um sistema de agentes para tutoria de conteúdo, diagnóstico de aprendizagem, motivação, criação de exercícios, avaliação e relatórios.

**Estado do repositório:** há documentação conceitual, mas ainda não há código-fonte, dependências ou testes versionados. A arquitetura e as possíveis expansões estão em [docs/arquitetura.md](docs/arquitetura.md).

Projeto da Residência Tecnológica do Porto Digital, com mentoria da Accenture.

## Estrutura preparada

```text
.
├── src/          # Implementação futura dos agentes
├── tests/        # Testes futuros da orquestração e dos agentes
├── docs/         # Arquitetura conceitual
├── assets/       # Diagramas e recursos visuais futuros
├── config/       # Exemplos de configuração, sem credenciais
└── README.md
```

As pastas de implementação estão preparadas, mas ainda não contêm um sistema executável. O arquivo de dependências será adicionado quando a tecnologia for definida.

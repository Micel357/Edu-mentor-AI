# Projeto de Agentes de IA: EduMentor AI

Este repositório documenta o sistema de agentes de IA **EduMentor AI**, que simula um processo de aprendizado personalizado. O projeto foi desenvolvido por um time que priorizou a **colaboração** e a **auto-organização** para entregar um sistema funcional.

## Metodologia de Desenvolvimento

Adotamos os princípios do Scrum de forma adaptativa, com foco na entrega contínua e na experimentação.

- **Scrum Master:** José (Guardião do Processo e Especialista em Setup)

- **Product Owner:** Mikael (Dono da Visão, Gestor de Conteúdo e Líder de Organização)

## Agentes Principais

O sistema é composto por 8 agentes, cada um com uma função pedagógica clara:

| Agente | Função Principal |
| --- | --- |
| **Luis** (Coordenador Pedagógico) | Orquestra o fluxo de aprendizado. |
| **Erika** (Agente de Diagnóstico) | Identifica as lacunas do aluno. |
| **TThiago** (Tutor de Conteúdo) | Explica os conceitos de forma didática. |
| **Sena** (Agente de Exercícios) | Cria atividades práticas de fixação. |
| **Mikael** (Agente Motivacional) | Apoia e incentiva o aluno. |
| **Julio** (Agente de Avaliação) | Avalia o domínio do conteúdo. |
| **Pedro** (Agente de Estratégias) | Sugere rotinas e métodos de estudo. |
| **Jonathan** (Agente de Relatório) | Consolida o progresso final. |
